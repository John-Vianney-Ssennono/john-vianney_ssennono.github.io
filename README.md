## 🎨 Design & Architecture

- **Apple Vision Design Touch:** Translucent frosted-glass panels (`backdrop-filter: blur(30px) saturate(190%)`), subtle specular lighting rims, and tactile pill controls.
- **Eye-Care Navy & Brown Palette:**
  - **Navy Blue:** Oxford deep navy (`#0a192f`), midnight navy surfaces, and royal blue accents.
  - **Cognac / Saddle Brown:** Rich amber-brown (`#92400e` / `#d97706`) and warm bronze highlights.
- **Instant Theme Switching:** Toggle between Dark and Light modes with zero-latency CSS custom properties, persistent via `localStorage` and synchronized with OS color preferences.
- **Interactive Hardware Simulators:**
  - **Autonomous Vision Glasses:** Real-time distance slider calculating ultrasonic echo timing ($\mu s$) and triggering embedded C threshold alerts.
  - **Door Reed Switch Circuit:** Live interactive magnetic switch visualizer with color-coded LED states.
- **High-Contrast Readability:** Strictly WCAG AAA compliant text across both light and dark themes for crystal-clear readability.
